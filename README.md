# AudioVerse

## De qué trata

AudioVerse es un **conversor de audios**, con la capacidad de cambiar
un archivo de audio de cualquier formato a otro. Además, podrá ser usado
también para transcribir los audios, siendo apoyado por medio de librerías y,
a futuro, por medio de inteligencia artificial.

## Tecnologías usadas

- OptimusUI: `ng add @openng/optimus-ui`.
- Iconos: `npm install @openng/icons`.

## Requisitos

- Noje.js: v24.15.0 o superior.
- npm: v11.12.1.
- Angular: v22.1.8.

## Instalaciones y Configuraciones

```bash
# Clonar el repositorio
git clone https://github.com

# Entrar al directorio
cd mi-proyecto-angular

# Instalar dependencias
npm install

```

## Servidor de desarrollo

Para iniciar un servidor de desarrollo usa:

```bash
ng serve
```

Una vez el servidor esté corriendo, abrir el navegador en `http://localhost:4200/`. La aplicación se recargará automáticamente cada que se modifique algo.
